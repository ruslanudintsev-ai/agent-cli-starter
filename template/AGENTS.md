# Agent operating instructions

Always read `.agents/rules/cli-standard.md`, `.agents/rules/self-learning.md`, `.agents/rules/agent-onboarding.md`, `.agents/rules/command-authoring.md`, `.agents/skills/cli-tools/SKILL.md` and `.agents/skills/cli-tools/gotchas.md` before project work. Prefer reusable `python __ENTRYPOINT__ <command> --json` commands over disposable scripts. Preserve all existing project rules and request approval for sensitive operations.

Use the evidence-first memory procedure in `.agents/rules/self-learning.md`; never promote private destination-project notes into public upstream contributions.

For verified improvements consult `.agents/skills/self-improvement/SKILL.md`, `.agents/skills/cli-tools/recipes.md`, and `.agents/backlog/cli-features.md`. These are private project-local notes unless explicitly reviewed for publication.

Never claim a newly scaffolded command is fully implemented: the default returns NOT_IMPLEMENTED and its acceptance placeholders fail. Ground completion in independent behavioral checks (positive and negative case) and evidence; see `.agents/rules/self-learning.md`.
