# Candidate CLI features (project-local backlog)

This is a list of **proposals**, not installed commands or authorization to execute them.

## Proposal template

### `<proposed-kebab-command>` — one-line goal
- **Why reusable:** Repeated task or measured problem.
- **Inputs / options:** Explicit proposed argparse interface.
- **Expected bounded JSON:** Status, fields and error cases; never unfiltered data.
- **Side effects / approval:** Read-only, mutating, destructive, network or privileged; expected dry-run behavior.
- **Tests / validation:** Success, failure, idempotence, privacy and platform constraints.
- **Decision:** proposed / approved / rejected / implemented, with reason.

Do not automatically scaffold or execute proposals. Remove duplicates after review.
