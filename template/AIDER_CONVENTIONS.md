# Aider conventions

Read `.agents/rules/cli-standard.md`, `.agents/rules/self-learning.md`, `.agents/rules/agent-onboarding.md`, `.agents/skills/cli-tools/SKILL.md` and `.agents/skills/cli-tools/gotchas.md`. Use `python __ENTRYPOINT__ <command> --json` for project operations. Start Aider with `aider --read AIDER_CONVENTIONS.md` (or configure the equivalent read file option). Do not overwrite existing project instructions.

For new commands follow `.agents/rules/command-authoring.md`; use `.agents/skills/self-improvement/SKILL.md` for evidence-based workflow improvement. Keep manually maintained recipes in `cli-tools/recipes.md` and proposed commands in `.agents/backlog/cli-features.md`.
